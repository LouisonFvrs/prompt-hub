# Prompt Hub

Prompt Hub est une plateforme web permettant de **partager, copier et noter des prompts**. Les utilisateurs peuvent écrire leurs propres prompts, les upvoter/downvoter, et modifier ou supprimer ceux qu'ils ont créés, le tout derrière un système d'authentification.

Ce projet a été réalisé dans le cadre de mon apprentissage d'**Angular**, en suivant le cours [Deviens un PRO sur Angular en 4 heures (+ mes secrets de Lead Dev)](https://www.youtube.com/watch?v=3llJm3LO1e4&t=14474s).

## ✨ Fonctionnalités

- 🔐 Authentification (inscription / connexion)
- 📝 Création, modification et suppression de ses propres prompts
- 📋 Copie rapide d'un prompt
- 👍👎 Système d'upvote / downvote sur les prompts
- 🔎 Consultation des prompts partagés par la communauté

## 🛠️ Stack technique

Le projet est découpé en deux parties :

- **`prompt-hub-frontend`** — Application Angular (TypeScript)

## 🚀 Installation

### Prérequis

- Node.js et npm

### Frontend

```bash
cd prompt-hub-frontend
npm install
ng serve
```

L'application sera accessible sur `http://localhost:4200`.

## 📚 Objectif du projet

Ce projet est avant tout un **projet d'apprentissage** visant à mettre en pratique les bases d'Angular : gestion des composants, routing, services, formulaires réactifs, communication avec une API REST, et gestion de l'authentification côté frontend.
